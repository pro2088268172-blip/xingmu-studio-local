# 星幕工坊本地站

本项目用独立的 Node.js 后端运行一个前端发布包。业务数据保存在本机；普通页面和素材操作不需要连接原站。原站发布包的页面组件和 `@` 标签机制仍在使用，部分脚本为了本地资源、上传和 API 路径做了改写；站点 Logo、图标和浏览器标题换成了星幕工坊。

**换电脑继续开发：**请使用包含运行资源的可移植开发包，并先读 [START_HERE.md](START_HERE.md)。公开 GitHub 仓库只包含自行编写的源码，单独克隆不会得到完整页面资源。

## 运行

需要 Node.js 24 或更新版本。在包含 `ai_comic/production/` 等运行资源的完整本地包目录执行：

```powershell
node server.mjs
```

打开 `http://127.0.0.1:4173/homepage`。数据会写入 `local-data.json`，上传文件写入 `local-upload/`；请自行备份这两处。设置 `JZZM_LOCAL_PORT` 可改变端口；设置 `JZZM_LOCAL_DATA` 为绝对路径可使用独立的数据文件。

## 异地访问

在主站运行时，再开一个终端执行：

```powershell
node public-gateway.mjs
```

网关只监听本机 `4176`，首次启动生成 `public-access.json`，其中有随机访问密码。网关会先验证密码，再转发页面、API、上传和 WebSocket。然后使用 Cloudflare Tunnel 等 HTTPS 隧道转发至 `http://127.0.0.1:4176`。例如：

```powershell
cloudflared tunnel --url http://127.0.0.1:4176 --no-autoupdate
```

无账号的 Quick Tunnel 会给一个随机 `https://*.trycloudflare.com` 地址。打开该地址时，用户名填 `local`，密码在本机 `public-access.json` 中。主站、网关和隧道进程必须持续运行；隧道重启后地址可能变化。需要长期固定域名时，应使用自己的域名和命名隧道。

`public-access.json`、`local-data.json` 和 `local-upload/` 不应放进公开仓库或分享包。公网使用者凭同一个密码访问同一份本机数据，没有独立账户和权限隔离。

## 已实现和验证的操作

- 首页、项目库、资产库、AI 实验室、无限画布等页面使用本机静态资源加载。
- 项目、文件夹、剧集、分镜的基础创建、编辑和保存。
- 首页的剧本、自由、小说原文和 SRT 模式创建表单；小说 TXT 上传保存到本机。SRT 项目从“创建剧集”上传字幕与配音，保存两个文件，并按每条字幕建立一条可编辑的分镜，显示字幕和时间；刷新后仍可读取。
- 剧本模式的粘贴导入、结构化剧本读取、集和场次增删、集名及场次内容自动保存、大纲、人物小传、前置钩子编辑与导出文本。新增场次后会选中对应场次，刷新后内容仍在。
- 项目复制时保留剧集、分镜、项目素材、已上传剧本记录和结构化剧本文档。上传文件地址按本机相对路径保存，换端口或公网隧道地址后仍可读取。
- 项目素材上传、显示；分镜提示词输入 `@` 后选择素材、保存，并在刷新后回显标签与图片。
- 分镜卡片本地图片上传、裁剪，以及 MP4 视频上传、保存和刷新回显；分镜图片及视频地址按本地相对路径持久化，换端口或公网入口后仍可读取。视频和音频文件支持分段读取，便于预览和拖动进度。上传接口的请求体上限为 64 MiB。
- 个人资产库上传角色图片并保存到本地列表；场景、道具使用同一套本地存储接口。
- 无限画布项目、节点及基础编辑保存。
- 公网网关的未授权拦截、带密码页面访问、API、WebSocket 和上传。

## 当前限制

剧本或小说的分集推理、要素推断、AI 图片／视频／语音生成、剧集成片、剪映草稿导出、积分结算、多人协作及公共内容服务需要原站未公开的后端或独立服务。当前没有这些能力；相关操作会返回明确的未接入结果。工作台启动时的模板列表为空、角色生成任务状态为空闲，不代表生成服务可用。小说项目创建成功不代表自动拆集完成。SRT 目前按字幕条目建立分镜，尚不具备原站可能采用的 AI 镜头规划、画面生成或配音对齐算法。前端可显示的菜单和选项不代表功能已实现。原站公开发布的压缩脚本也不是原始工程源码。以保存的原版发布文件哈希对比，本地 189 个 JavaScript 文件中有 23 个为了本地化而修改，因此也不能称为逐字节相同的原版前端。

公开仓库只包含自行编写的服务端、网关、入口、品牌资源及说明，不包含第三方前端发布包或用户数据。详见 [第三方资源说明](THIRD_PARTY.md)。完整本地包包含运行所需的第三方资源，其授权不由本项目授予。
