# 星幕工坊本地站

本项目用独立的 Node.js 后端运行一个前端发布包。业务数据保存在本机；普通页面和素材操作不需要连接原站。原站发布包的页面组件和 `@` 标签机制仍在使用，部分脚本为了本地资源、上传和 API 路径做了改写；站点 Logo、图标和浏览器标题换成了星幕工坊。

**换电脑继续开发：**请使用包含运行资源的可移植开发包，并先读 [START_HERE.md](START_HERE.md)。公开 GitHub 仓库只包含自行编写的源码，单独克隆不会得到完整页面资源。

## 运行

需要 Node.js 24 或更新版本。在包含 `ai_comic/production/` 等运行资源的完整本地包目录执行：

```powershell
node server.mjs
```

打开 `http://127.0.0.1:4173/homepage`。数据会写入 `local-data.json`，上传文件写入 `local-upload/`；请自行备份这两处。设置 `JZZM_LOCAL_PORT` 可改变端口；设置 `JZZM_LOCAL_DATA` 为绝对路径可使用独立的数据文件。

## 异地访问

在主站运行时，再开一个终端执行：

```powershell
node public-gateway.mjs
```

网关只监听本机 `4176`，首次启动生成 `public-access.json`，其中有随机访问密码。网关会先验证密码，再转发页面、API、上传和 WebSocket。然后使用 Cloudflare Tunnel 等 HTTPS 隧道转发至 `http://127.0.0.1:4176`。例如：

```powershell
cloudflared tunnel --url http://127.0.0.1:4176 --no-autoupdate
```

无账号的 Quick Tunnel 会给一个随机 `https://*.trycloudflare.com` 地址。打开该地址时，用户名填 `local`，密码在本机 `public-access.json` 中。主站、网关和隧道进程必须持续运行；隧道重启后地址可能变化。需要长期固定域名时，应使用自己的域名和命名隧道。

`public-access.json`、`local-data.json` 和 `local-upload/` 不应放进公开仓库或分享包。公网使用者凭同一个密码访问同一份本机数据，没有独立账户和权限隔离。

## 已实现和验证的操作

- 首页、项目库、资产库、AI 实验室、无限画布等页面使用本机静态资源加载。
- 项目、文件夹、剧集、分镜的基础创建、编辑和保存。
- 首页的剧本、自由、小说原文和 SRT 模式创建表单；小说 TXT 上传保存到本机。SRT 项目从“创建剧集”上传字幕与配音，保存两个文件，并按每条字幕建立一条可编辑的分镜，显示字幕和时间；刷新后仍可读取。
- 自由模式追加上传的剧本文件名与地址可保存到项目，刷新后回显；上传后的自动要素推理仍需生成服务。
- 剧本模式的粘贴导入、结构化剧本读取、集和场次增删、集名及场次内容自动保存、大纲、人物小传、前置钩子编辑与导出文本。新增场次后会选中对应场次，刷新后内容仍在。
- 项目复制时保留剧集、分镜、分镜素材历史、项目素材、已上传剧本记录和结构化剧本文档。上传文件地址按本机相对路径保存，换端口或公网隧道地址后仍可读取。
- 项目素材上传、显示，工作台素材列表按角色／场景／道具类型读取；分镜提示词输入 `@` 后选择素材、保存，并在刷新后回显标签与图片。
- 个人资产库中的本地角色／场景／道具图片可导入项目素材库，重复导入会被拒绝；项目素材详情接口返回可供 `@` 引用的图片，复制项目会保留导入结果。
- 可将一个项目中选定的素材复制到另一个本地项目，保留图片与引用数据，并跳过已复制的素材。已在隔离浏览器中从空角色库点“从其他项目导入”→选择源项目素材→“一键导入”，刷新后目标项目仍显示该角色。
- 项目中的本地图片素材可按勾选的形象同步到个人资产库；同名资产会先报告冲突，再按选择合并图片或覆盖。此冲突判断使用本地名称和文件地址。
- 更新项目素材的本地图片时保留旧版本，可在素材历史中选择旧图并切回；旧版本与当前版本随项目数据保存。已在隔离浏览器中点开角色编辑的“角色历史记录”，选择旧图并应用，刷新后图片仍为所选版本。
- 分镜卡片本地图片上传、裁剪，以及 MP4 视频上传、保存和刷新回显；分镜图片及视频地址按本地相对路径持久化，换端口或公网入口后仍可读取。视频和音频文件支持分段读取，便于预览和拖动进度。上传接口的请求体上限为 64 MiB。
- 分镜图片、视频清单统一保存为 URL 字符串；旧数据中对象形式的媒体条目在读取时转换，避免剧本工作台因媒体数据格式报错。
- 个人资产库上传角色图片并保存到本地列表；场景、道具使用同一套本地存储接口。
- “我的音色”可保存已上传的本地 WAV／MP3／AAC／M4A 音频，支持列表、详情、改名和删除记录。隔离浏览器中已验证 WAV 上传、保存、列表回显和选择使用；AAC／M4A 的接口接受和媒体响应已补齐，未逐格式验证浏览器解码。音色生成仍需独立服务。
- 本地资产 API 支持图片和音频创建、子素材编辑与删除、资源组改名、收藏、隐藏、可见范围和主形象选择，并把变更写入本地数据。`node local-api-check.mjs` 使用隔离数据验证这些接口及重启读取。
- 分镜的图片／视频创作模式切换与剧集精细模式设置通过本地 API 保存，重载后仍可读取。
- 手工上传新图片或视频时保存分镜素材历史；历史 API 可按分镜或剧集读取，并选回旧素材。项目复制保留历史，删除剧集清理对应历史。每个分镜最多保留最近 50 条本地素材历史。
- 可把已上传的图片／视频单独保存到项目历史，按素材类型、剧集、关键词和收藏状态筛选；项目复制与剧集删除会同步处理历史记录。隔离浏览器已验证项目历史弹窗中的本地图片显示、收藏和“仅看收藏”筛选。工作台侧栏的“历史库”读取当前剧集的分镜历史，因此仅有独立项目历史时，弹窗有内容而侧栏仍可为空。
- 无限画布项目、节点及基础编辑保存。
- 无限画布项目可在个人文件夹之间移动，重新打开后保留所在位置；画布卡片的打开按钮和移动菜单已在隔离浏览器中点击验证。
- 无限画布的自定义图片预设可创建、编辑、列出和删除，名称及前后缀提示词保存在本机。首次启动提供一条可编辑、可删除的本地示例预设，使空数据时也能打开预设菜单；创建、修改、删除均已在隔离浏览器中点击验证。
- 三维导演台的名称、备注和场景配置可在项目内创建、保存、读取与删除；项目复制时保留配置。隔离浏览器中从分镜创建导演台并修改天空颜色，刷新后配置仍在。俯视图和图片生成仍需生成服务。
- 无限画布更新的增量变更查询：节点和连线的新增、修改、删除可按版本读取，记录保存在本地数据文件中（最多保留最近 100 次更新）。
- SRT 工作台“一键导出”可下载含已上传图片、MP4、配音和 SRT 的 ZIP；前端根据本地 API 返回的素材清单及草稿数据生成剪辑草稿 JSON。已在浏览器验证 ZIP 下载、草稿 JSON 可解析且媒体字节与源文件一致。
- 剧本工作台“一键导出”已在隔离浏览器中下载 ZIP，包含已上传的图片和可解析的草稿 JSON；ZIP 内图片与源文件的 SHA-256 一致。页面本次调用 `/storyboard/api/export/jsonBySeriesId`；`scriptJsonBySeriesId` 兼容接口仍仅经过隔离 API 检查。草稿尚未在剪映客户端验证导入。
- 公网网关的未授权拦截、带密码页面访问、API、WebSocket 和上传。

## 当前限制

剧本或小说的分集推理、要素推断、AI 图片／视频／语音生成、剧集成片、积分结算、多人协作及公共内容服务需要原站未公开的后端或独立服务。当前没有这些能力；相关操作会返回明确的未接入结果。工作台启动时的模板列表为空、角色生成任务状态为空闲，不代表生成服务可用。小说项目创建成功不代表自动拆集完成。SRT 目前按字幕条目建立分镜，尚不具备原站可能采用的 AI 镜头规划、画面生成或配音对齐算法。导出的草稿 JSON 尚未在剪映客户端验证导入兼容性，不能称为已验证的剪映工程。画布增量变更可用于同一站点的版本查询，但尚无多人身份、权限和实时协作服务。资产的其他编辑入口和分镜历史操作虽经过隔离 API 检查，仍未逐项完成原站与本地界面的端到端对照。前端可显示的菜单和选项不代表功能已实现。原站公开发布的压缩脚本也不是原始工程源码。以保存的原版发布文件哈希对比，本地 189 个 JavaScript 文件中有 23 个为了本地化而修改，因此也不能称为逐字节相同的原版前端。

公开仓库只包含自行编写的服务端、网关、入口、品牌资源及说明，不包含第三方前端发布包或用户数据。详见 [第三方资源说明](THIRD_PARTY.md)。完整本地包包含运行所需的第三方资源，其授权不由本项目授予。

REA 静态证据摘要与可验证边界见 [REA_FINDINGS.md](REA_FINDINGS.md)。
